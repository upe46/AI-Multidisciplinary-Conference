Antigravity × GitHub チーム開発・完全マニュアル

このマニュアルは、「Antigravity（AI）はインストールしたけれど、GitHubはこれから導入する」という初学者のチームが、迷うことなくアプリを共有して共同開発できるようになるまでの手順をまとめたものです。

難しいコマンド（黒い画面の操作）は極力使わず、「AIにお願いする（プロンプトを打つ）」ことで自動化する最強の開発フローを構築します。

1. 【準備】GitHubに共有の「箱」を作る

まずはクラウド上（インターネット上）に、ソースコードを共有するための箱（リポジトリ）を作ります。

  1. GitHub にアクセスし、アカウントを作成します（チームで1つのアカウントを共有するか、代表者が作ります）。
  2. ログイン後、画面右上の「＋」ボタンから 「New repository」 をクリックします。
  3. Repository name にアプリの名前（例：my-app）を入力します。
  4. 「Public」（公開）を選びます（後でテスト用URLを発行するため）。
  5. 一番下の 「Create repository」 緑色ボタンを押します。
  6. 次の画面で表示されるURL（例: https://github.com/名前/my-app.git）をコピーしておきます。
💡 チームメンバーは全員GitHubアカウントを作成し、このリポジトリの「Settings」>「Collaborators」から招待しておくとベストです。

2. 【連携】AntigravityとGitHubを繋ぐ

Antigravityを立ち上げ、先ほど作った「箱」を自分のPCにダウンロードします。

  1. 空のフォルダを自分のPC（デスクトップ等）に作ります。
  2. Antigravityでその空フォルダを開きます。
  3. Antigravityのチャット画面で、AIに以下のプロンプトを送ります。
💬 AIへのプロンプト例：

先ほどGitHubにリポジトリを作りました。このURL（https://github.com/〜〜.git）の中身を、今開いているフォルダにダウンロード（git clone）してください。

※この時、GitHubのログイン画面が出たら指示に従ってログインします。

3. 【自動化設定】AIにチーム開発のルールを教え込む

初学者が一番つまづくのが「Gitの同期（PullやPush）」です。これをすべてAIに自動でやらせる設定を最初に行います。

💬 AIへのプロンプト例：

チームで共同開発を行います。以下の内容でAIの行動ルール（.agents/AGENTS.md）を作成し、作成後は自動的にGitHubへアップロード（git push）してください。

【ルール内容】
1. 作業を始める前には、必ず自動で git pull を行い、他のメンバーの最新状態を受け取ること。
2. コードの修正や作成が終わったら、必ず自動で git add .、git commit、git push を行い、GitHubに自動でアップロードすること。ユーザーに手動操作を求めないこと。

これで、AIが勝手にルールファイルを作成し、GitHubにアップロードしてくれます。以降、どのメンバーがAntigravityを使っても、自動的にデータが同期される最強の環境が完成します。

4. 【公開設定】テストプレイ用のURLを発行する

完成した（あるいは作り途中の）アプリをスマホなどで確認できるようにします。

  1. GitHubのリポジトリ画面を開き、「Settings」 をクリックします。
  2. 左メニューから 「Pages」 をクリックします。
  3. Sourceを 「Deploy from a branch」 にし、Branchを 「main」 にして「Save」を押します。
  4. 1〜2分待つと、画面上部にURLが発行されます。これをチームで共有します。

5. 【日常の作業】みんなでアプリを改造していく

準備は整いました！今後の開発は、他のメンバーも含め以下のプロンプトの型を使ってAIにお願いするだけで進みます。

パターンA：新しく作業を始める時

自分が作業を始める前は、必ず他の人が作った最新データを受け取るため、AIに一言声をかけます。

💬 AIへのプロンプト例：

作業を始めます。まずは最新のデータをGitHubから同期（git pull）してください。

パターンB：アプリの機能を追加・変更する時

AIに要望を伝えます。AIは作業が終わると、ルールに従って自動的にGitHubへ変更をアップロード（Push）してくれます。

💬 AIへのプロンプト例：

トップページに「お問い合わせ」ボタンを追加して、クリックしたらポップアップが出るようにしてください。
作業完了後、ルールに従ってGitHubへPushし、テスト用URLに反映させてください。

⚠️ エラーなどでAIが自動アップロード（Push）に失敗した場合

たまに自動アップロードが止まることがあります。その時は直接AIにお願いします。

💬 AIへのプロンプト例：

今の変更を保存して、GitHubにアップロード（git add, commit, push）してください。
