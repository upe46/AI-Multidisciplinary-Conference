# Antigravity Agent Rules for this Project

## Auto Git Synchronization
When working in this repository, you MUST automatically handle Git synchronization to ensure all team members have the latest updates and the GitHub Pages URL stays up to date.

1. **Before starting ANY code changes:**
   - Automatically run `git pull` to fetch the latest updates from other team members.

2. **After completing code changes:**
   - Automatically commit the changes with a descriptive message (`git add .` and `git commit -m "..."`).
   - Automatically push the changes to GitHub (`git push`).
   - Do NOT ask the user to do this manually. You must execute these commands yourself as the final step of your work.
