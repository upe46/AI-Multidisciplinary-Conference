# AI模擬多職種カンファレンスルーム

医学生および新人医療従事者を対象とした、AIによる多職種連携カンファレンスのシミュレーションを行うWebアプリケーションです。

## 特徴
- **マルチロールシミュレーション**: 医師、看護師、管理栄養士、ST等の専門職AIが、それぞれの専門的視点から議論を行います。
- **拡張性の高いシナリオ設計**: シナリオやプロンプト設定は `scenarios/` 配下のJSONファイルで管理しており、新しいカンファレンス（リハビリ、退院支援など）への拡張が容易です。
- **音声入力対応**: Web Speech APIを利用し、実際のカンファレンスのように音声での発言・質問が可能です。
- **モダンなUI**: 直感的に操作できるグラスモーフィズムデザインのチャットUIを採用しています。

## 環境構築と実行方法

このアプリケーションは、Node.js等の複雑なビルド環境を必要としないプレーンなHTML/CSS/Vanilla JSで構築されています。

1. リポジトリをクローンまたはダウンロードします。
2. 以下のいずれかの方法でローカルサーバーを立ち上げます。
   - **VS Codeを使用する場合**: 拡張機能「Live Server」をインストールし、`index.html`を右クリックして「Open with Live Server」を選択します。
   - **Pythonを使用する場合**: ターミナルで本ディレクトリに移動し、`python -m http.server 8000` を実行します（ブラウザで `http://localhost:8000` にアクセス）。
   - **Node.jsを使用する場合**: `npx serve .` などのコマンドを利用できます。

※ ブラウザで直接 `index.html` を開くと、CORS（Cross-Origin Resource Sharing）の制限によりシナリオJSONファイルの読み込みに失敗する可能性があるため、必ずローカルサーバー経由で実行してください。

## APIキーの設定

本アプリケーションはGemini APIを利用してAIの応答を生成します。
`js/api.js` の1行目にある `API_KEY` の値を、ご自身の有効なGemini APIキーに置き換えて使用してください。

```javascript
// js/api.js
const API_KEY = "あなたのAPIキーをここに入力してください";
```

## 👥 チーム開発の黄金ルール

チームメンバーで安全かつ円滑に共同開発を進めるための基本ルールです。

1. **作業開始時**: 必ずターミナルで `git pull` を実行し、他のメンバーの最新の変更を自分のPCにダウンロードします。
   ```bash
   git pull origin main
   ```
2. **作業中**: Antigravity等を使って機能を変更・追加し、ローカル環境（`http://localhost:8000`）で動作テストします。
3. **作業終了時**: 変更をコミットし、`git push` でGitHubリポジトリにアップロードします。
   ```bash
   git add .
   git commit -m "変更内容を簡潔に記述"
   git push origin main
   ```

## 今後の拡張（グループ開発向け）

新しいカンファレンスを追加する場合は、以下の手順で行います。
1. `scenarios/nst.json` を参考に、新しいシナリオのJSONファイル（例: `rehab.json`）を作成します。
2. アプリケーション起動時に読み込むシナリオを切り替えられるよう、UI（`index.html`）およびロジック（`js/app.js`）を拡張します。

## 注意事項
- 音声入力機能（マイクボタン）は、対応しているブラウザ（Google Chrome, Edge等のChromium系ブラウザ）でのみ動作します。
